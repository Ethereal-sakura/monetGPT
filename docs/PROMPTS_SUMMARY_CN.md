# MonetGPT 提示词总览

## 简介

MonetGPT 使用两种主要场景的提示词：
1. **推理阶段** - 用于生成图像编辑建议
2. **数据集生成** - 用于训练数据的推理生成

---

## 一、推理阶段提示词（用于实际图像编辑）

### 使用位置
文件：`inference/core.py`

### 工作流程
推理使用**两轮对话**：

#### 第一轮：分析阶段
**系统提示词：**
```
你是一个在 Adobe Lightroom 方面具有专业知识的高级图像编辑助手。
```

**用户提示词（简化版）：**
```
分析提供的图像，制定专业级的编辑计划，使用 Adobe Lightroom 中可用的操作来解决 {操作类型} 方面的问题。

你的任务是识别图像中的所有视觉问题，并提出精确、优化的调整建议。

为这张照片创建一个专业的编辑计划，列出解决识别问题所需的**最佳**调整。

对于每个调整，遵循以下格式：
调整：[提及需要进行的调整。例如：**调整：** 白色需要大幅降低。]
问题：[解释图像中的具体问题，关注它如何对照片产生负面影响，尽可能使用图像中的上下文。]
解决方案：[描述调整将如何解决问题]

你应该确保应用这些调整将导致**最佳**图像，具有专门为该图像调整的平衡调整值。

{风格指导}
{额外指令}
```

**支持的操作类型：**
1. `white-balance-tone-contrast` - 曝光、对比度和色调范围调整（黑色、对比度、高光、阴影、白色、曝光）
2. `color-temperature` - 白平衡和全局饱和度（色温、色调、饱和度）
3. `hsl` - 选择性颜色调整（各种色相/亮度/饱和度调整）

**支持的风格：**
- `balanced`（平衡）：追求平衡编辑，保持自然外观
- `vibrant`（鲜艳）：追求鲜艳有冲击力的颜色，适合社交媒体
- `retro`（复古）：追求怀旧复古氛围，柔和褪色的色彩

#### 第二轮：JSON 生成阶段
**提示词（简化版）：**
```
根据编辑计划和原始图像，以 JSON 格式告诉编辑这张照片所需的**最佳**调整值。
所有调整值的范围是 -100 到 +100。

以下图例可用于映射强度值：
1-12：非常轻微
13-24：轻微
25-36：温和
37-48：中等
49-60：明显
61-72：显著
73-84：非常显著
85-100：极其强烈

{风格指导}
{额外指令}
```

## 二、数据集生成提示词（用于训练）

### 使用位置
文件：`dataset/query_llm.py`

MonetGPT 使用三种类型的"谜题"来训练模型理解图像编辑操作：

### Puzzle 1：单操作分析

**用途：** 教授单个图像修饰操作

**系统提示词：**
```
你是 Lightroom 图像编辑方面的专家助手。你将并排比较图像（图像并排拼接，所以你绝对可以做到这一点）
```

**用户提示词要点：**
- 分析原始和编辑后的并排图像
- 识别应用的操作（如饱和度、对比度等）
- 确定调整值（-100 到 +100）
- 提供逐步推理

**示例输出格式：**
```
1. 应用的编辑操作：饱和度调整
2. 调整值：+25% 饱和度

推理：
步骤 1：观察到编辑后的图像中的颜色比原始图像更鲜艳。
步骤 2：识别出这种鲜艳度的增加在所有颜色中是均匀的，指向饱和度调整而非单个颜色通道的变化。
步骤 3：与已知饱和度调整的参考图像进行比较，将变化近似为 +25%。

总结：
应用的操作是"饱和度调整"，近似值为 +25%。
```

### Puzzle 2：多版本比较

**用途：** 教授参数值关系

**提示词要点：**
- 显示同一图像的 4 个版本（a、b、c、d），具有不同的调整值
- 要求模型按从低到高的调整值对它们进行排序
- 识别哪个版本是最佳的
- 解释为什么该版本最佳，详细描述视觉元素

**关键要求：**
- 包含尽可能多的图像上下文
- 避免模糊陈述，指出具体问题（如阴影细节丢失、不自然的亮度等）
- 解释最佳级别如何在保持关键细节的同时提高图像质量

### Puzzle 3：综合编辑计划

**用途：** 教授完整的修饰工作流程

**系统提示词：**
```
你是 Adobe Lightroom 方面的高级图像编辑助手。你有能力分析并排的图像对（左边是原始的，右边是编辑后的）。
你的任务是生成一组指令，识别原始图像中的问题并提供合理的调整来解决它们。

描述解决方案时，遵循以下规则：
1. 不要直接引用当前编辑后的照片；而是用将来时表达改进（例如，"编辑后的图像将有..."）
2. 为每个建议的调整提供详细理由，将它们与原始图像中发现的特定问题联系起来
3. 使用描述性图例描述调整强度，而不是数值
4. 避免模糊或通用的陈述——准确说明原始图像有什么问题以及调整如何解决该问题
5. 基于并排比较中看到的可见变化来证明你的理由
```

**用户提示词要点：**
- 详细检查并排比较图像
- 识别原始图像中的所有问题（曝光过度的高光、缺乏对比度、色偏等）
- 为每个调整使用特定格式：
  - **调整：** [需要进行的调整]
  - **问题：** [原始图像中的具体问题]
  - **解决方案：** [调整将如何解决问题，用将来时]
- 引用图像中的显著视觉特征
- 连接每个编辑到原始照片中需要改进的特定元素

## 四、关键设计特点

1. **两阶段推理**：先分析后生成参数，确保可解释性
2. **强度描述**：使用描述性术语（轻微、中等、显著等）而非数字
3. **上下文丰富**：要求详细描述图像内容和具体问题
4. **风格可控**：支持多种编辑风格配置
5. **可解释性**：所有调整都有明确的问题-解决方案对应关系
